# BrightWeb — Task 5

## Project Overview

BrightWeb is a responsive static website created for the Web Development Internship Task 5.

**Objective:** Deploy a static website using GitHub Pages for free.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## Features

- Responsive design for mobile, tablet, and desktop
- Navigation menu with working section links
- Interactive mobile navigation
- Automatic copyright year
- Clean and modern layout
- Free static website hosting with GitHub Pages

## Project Files

- `index.html` — website structure
- `style.css` — website styling and responsive layout
- `script.js` — interactive navigation and page behavior
- `README.md` — project documentation

## How to Run

1. Download or clone the repository.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Alternatively, use the Live Server extension in VS Code.

## Deployment Using GitHub Pages

1. Create a public GitHub repository.
2. Upload all four project files to the repository root.
3. Commit and push the files to the `main` branch.
4. Open the repository's **Settings → Pages**.
5. Select **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder.
7. Click **Save** and wait for deployment.
8. Open the published website URL.

For a personal website repository named `YOUR-USERNAME.github.io`, the website URL will be:

`https://YOUR-USERNAME.github.io/`

Replace `YOUR-USERNAME` with your GitHub username.

## Learning Outcome

This project demonstrates the basics of building a responsive static website, using Git for version control, and deploying a website with GitHub Pages.
